## 📖 项目简介 (Overview)

**missavaiVPN 评测实验室 (`missavaivpn.blog`)** 是一个面向跨境电商、海外研发、AI 生产力及个人出海群体的**高权威性技术评测与决策辅助门户**。

本项目完全基于 **Astro 7 SSG 静态预渲染架构** 驱动，彻底摆脱传统动态 CMS 的安全漏洞与缓慢首屏体验，追求 **0 客户端渲染门槛 (Zero CSR)**、**极致 Lighthouse 跑分** 与 **专著级深度内容（E-E-A-T & GEO 优先）**。

## 🚀 本地开发与构建 (Getting Started)

### 前置环境需求
* [Node.js](https://nodejs.org/) `>= 18.17.0` (推荐 LTS v20 或 v22)
* 包管理器：`npm` / `pnpm` / `yarn`

### 1. 克隆代码仓库
```bash
git clone https://github.com/sksksk98698-source/missavaivpn.blog.git
cd missavaivpn.blog
```

### 2. 安装项目依赖
```bash
npm install
```

### 3. 启动本地开发服务器
```bash
npm run dev
```
启动后在浏览器中打开 `http://localhost:4321` 即可体验实时热更新 (HMR)。

### 4. 生产环境构建打包
```bash
npm run build
```
编译完成后，全站 67 个预渲染 HTML 页面及相关静态资产将输出到 `dist/` 目录。

### 5. 本地预览生产构建制品
```bash
npm run preview
```

## 🌐 线上部署建议 (Deployment)

由于本项目为纯静态 SSG 架构，可以一键部署在任何现代边缘网络平台上：

### 推荐托管平台
* **Cloudflare Pages**：
  * 构建命令：`npm run build`
  * 输出目录：`dist`
  * 优势：全球 Anycast CDN 节点加速，免费 HTTPS，支持配置 301 重定向与边缘安全规则。
* **Vercel** / **Netlify**：
  * 框架预设：`Astro`
  * 构建命令：`astro build`
  * 输出目录：`dist`
* **独立 Nginx 服务器**：
  * 将 `dist/` 目录上传至服务器根目录，配置 `try_files $uri $uri/ =404;` 即可享受毫秒级超快响应。
